# Amanda's Portfolio

Interactive product design portfolio with case studies, animations, and bilingual support.

## Structure

- `index.html` — Main portfolio landing page (Portfolio Feira)
- `case-naches.html` — Naches case study
- `case-noticiato.html` — Noticiato case study
- `assets/` — Images and media files
- `support.js` — DC runtime support

## Navigation

All pages are interconnected:
- Home (index.html) links to both case studies
- Case studies link back to home
- Language toggle (PT/EN) works across all pages

## How to run

1. Open `index.html` in a browser
2. Navigate between pages using links
3. Try the language toggle in the top right

## Deploy

- Host on GitHub Pages, Vercel, or any static host
- No build step needed — all files are standalone HTML
- Assets must be in the `assets/` folder

## Features

- Responsive design (mobile to desktop)
- Smooth animations and transitions
- Bilingual interface (Portuguese/English)
- Self-contained pages (no external dependencies)
